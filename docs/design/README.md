## 工作方式

- 设计文档是实现的唯一依据。实现中发现需要偏离设计时，先改文档、征得同意，再改代码。
- 每个阶段完成后，在本地预览给作者检查；作者确认后才提交。agent 从不推送。
- 下载外部数据、删除未提交文件、新增依赖之前，必须先征得作者同意。
