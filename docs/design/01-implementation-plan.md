# 分阶段实施计划

> 状态：**第二稿**，已吸收 2026-11-17 的审阅意见
> 依据：[00-overall-design.md](./00-overall-design.md)
> 原则：先做模板，再填真实内容。模板阶段只用现有的 6 篇论文和 DINOv3 01、02 草稿作测试数据，不发布。

## 每个阶段的固定流程

1. 开工前先看 `git status`，不覆盖未提交的改动。
2. 新写的代码按设计文档 §9.1 写足中文注释。完成后 `npm run build` 必须通过，再用 `npm run preview` 在本地给你看。
3. 交付时列出已验证和未验证的项目，不用“应该没问题”代替检查。
4. 你确认后，由你说“提交”才提交。**agent 从不推送。**
5. 以下三件事要在执行时单独征得你的同意：下载外部数据（PI-CAI）、删除未提交的文件、新增上表以外的依赖。

## Phase 0：清理与护栏

- 写 `AGENTS.md`（先写规则；各项操作手册在对应阶段补上）和 `CLAUDE.md`（只有一行 `@AGENTS.md`）。
- 按设计文档 §10 删除旧网站的全部页面、路由、数据和内容，不做重定向。**DINOv1 系列和工作区里的未提交改动，删除前再确认一次。**

**验收**：构建通过；旧页面不再生成；没有失效的内部链接。

## Phase 1：基础框架

- 切分并加载字体；整理颜色 token；保留三种主题。
- 导航：四个标签，加搜索按钮（先占位）、语言切换、主题切换。
- 页面框架：页头在向下滚动时自动隐藏，页脚；跨文档 View Transitions；全局的减少动态效果规则。
- `sitemap.xml`，并在 `public/robots.txt` 里加回 `Sitemap:` 一行（Phase 0 删除旧 sitemap 时一并去掉了）。

**验收**：在 320、768、1280px 三个宽度下，亮色、暗色、中文、英文各检查一遍；中文页首屏字体下载量小于 500KB；没有横向滚动。

## Phase 2：About Me 与 Publications

- About 页：占位头像，沿用旧网站的简介文案（从 `main` 分支的旧组件里取），CV 按页面语言下载。
- Publications：新的 YAML 结构；把现有 6 篇转换过去（只转格式，不改写事实）；列表页、详情页、Cite 块、`citation_*` meta 和 JSON-LD。
- 在 `AGENTS.md` 里写“添加论文”的操作手册。

**验收**：6 篇在列表和详情页都能正常显示；BibTeX 可以复制；作者标记正确；HTML 中有 citation meta。

## Phase 3：Posts 与 Obsidian 流程

- **3a 同步手册**：把设计文档 §7.1 的步骤写进 `AGENTS.md` 的“同步笔记”一节，不写同步脚本。按手册把 DINOv3 01、02 作为草稿同步一次，以此验证手册。
- **3b 构建插件**：双链、块引用、嵌入、图注、视频、Admonition、callout、MathJax、按需加载的 Mermaid。构建时校验 frontmatter 和引用，问题以警告或错误输出。
- **3c 阅读页**：大纲、阅读进度条、系列导航、悬停预览、反向链接、局部关系图。
- **3d 索引页**：分类和系列视图；全站关系图；Pagefind 搜索。
- **3e 翻译流程**：用 DINOv3 01、02 草稿测试，只在本地进行。

**验收**：

- DINOv3 01、02 在本地完整渲染：Admonition 样式、视频、图注、块引用跳转、Mermaid 都正常。
- 指向未创建笔记的链接显示为灰色，并以灰色节点出现在关系图里。
- 生产构建中不含任何草稿。
- 中英文都能搜索到。

## Phase 4：首页 3D MRI

- **4a**：征得你同意后，下载 PI-CAI 的一例；核对许可；编写预处理脚本。
- **4b**：three.js 体渲染，加腺体轮廓和病灶高亮；鼠标跟随转动 ±20°。
- **4c**：定下背景色和强调色，回填到全站的颜色 token。
- **4d**：静态图降级，覆盖手机、开启减少动态效果、不支持 WebGL2 三种情况。
- 在 `AGENTS.md` 里写“更换首页 3D 数据”的操作手册。

**验收**：

- 在 M 系列 Mac 上稳定 60fps。
- 静态降级在上述三种情况下都正确生效。
- 首页 JS 和体数据的体积在预算内。
- 数据来源署名可见。

## Phase 5：Albums

- 数据结构、EXIF 读取、图片处理。
- 索引页和相册页各出两版样稿，你选定后再定稿。
- PhotoSwipe 灯箱；构建时的站点体积提醒。
- 在 `AGENTS.md` 里写“添加相册”的操作手册。

**验收**：

- 本地图片和链接图片都能正常显示。
- EXIF 信息正确。
- 灯箱支持键盘和手势操作。
- 降级生效。

## Phase 6：全站验收

在真实浏览器里检查：

- 宽度：320、375、768、1024、1280、1440px；
- 主题：亮色、暗色、自动；
- 键盘操作；减少动态效果；
- 浏览器：Safari、Chrome、Firefox；
- Lighthouse 的性能和可访问性评分；
- 中英文路由完整；sitemap；404 页面。
